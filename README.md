# Controle de Desempenho de Filiais

Sistema desenvolvido em Python para gerenciar dados de faturamento e clientes de filiais.

## Funcionalidades

Cadastro de dados de faturamento e clientes  
Relatório de desempenho por filial  
Atualização dinâmica de dados  
Busca por metas de faturamento  
Tratamento robusto de erros
